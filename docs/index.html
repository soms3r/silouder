MULTI-TRANSPORT LAYERS

Zero-Infrastructure Routing

Silouder does not rely on a single communication channel. An intelligent transport router continuously tests available links and routes encrypted packets across the most efficient path.

Nearby Bluetooth P2P

Briar-inspired proximity discovery and offline peer-to-peer sync. Exchanges message vectors when physical peers are within Bluetooth range without ever touching the internet.

BLE Advertising Gossip Vectors Zero Tower

Online LAN Sockets

Direct peer sockets over WiFi, ad-hoc hotspots, or reachable local IPs on port 8888. Allows ultra-fast high-throughput sync across local networks without central chat servers.

TCP Sockets Port 8888 Zero Cloud Server

LoRa Radio Mesh (Meshtastic)

Integrates with external SX1262 LoRa hardware modems via BLE. Supports long-range sub-GHz packet broadcast, multi-hop mesh repeaters, and packet MTU fragmentation.

SX1262 Modem 915 / 868 MHz Meshtastic BLE

Tor v3 Onion Sockets

End-to-end anonymous circuits over Tor. Deterministically derives v3 onion addresses from node identity keys, providing censorship-resistant routing when the global web is censored.

MIL-GRADE CRYPTOGRAPHY

End-to-End Encrypted by Default

Every byte transmitted by Silouder is encrypted locally before ever touching a radio or socket transport. Even intermediate mesh repeater nodes only see ciphertext.

  • ✓

    AES-256-GCM AEAD

    Authenticated encryption with associated data provides both confidentiality and cryptographic tamper protection.

  • ✓

    HMAC-SHA256 Signatures

    Tamper-proof packet verification ensures data cannot be forged or altered in transit by rogue mesh repeaters.

  • ✓

    Local Identity Key Derivation

    Identities are generated entirely offline on your device using cryptographic entropy. No phone number, email, or account needed.

  • ✓

    Zero Cloud & Zero Telemetry

    No analytics, no trackers, no Google Play Services dependency. 100% compliant with F-Droid and GPL-3.0 standards.

CryptoEngine.kt • AES-256-GCM AEAD
// High-Security AEAD Envelope Encryption fun encryptPayload( plaintext: String, keyBytes: ByteArray ): EncryptedEnvelope { val iv = ByteArray(12) secureRandom.nextBytes(iv) val cipher = Cipher.getInstance("AES/GCM/NoPadding") val spec = GCMParameterSpec(128, iv) cipher.init(Cipher.ENCRYPT_MODE, SecretKeySpec(keyBytes, "AES"), spec) val ciphertext = cipher.doFinal(plaintext.toByteArray()) val signature = computeHmacSha256(ciphertext, keyBytes) return EncryptedEnvelope( ciphertextBase64 = encode(ciphertext), ivBase64 = encode(iv), macSignatureHex = signature ) }
